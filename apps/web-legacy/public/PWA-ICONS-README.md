# PWA Icons Setup Instructions

## Required PNG Icons

Your PWA needs the following PNG icon files:

1. `icon-192.png` (192x192 pixels)
2. `icon-512.png` (512x512 pixels)

## How to Create the Icons

### Option 1: Use the Icon Generator (Recommended)

1. Open `create-icons.html` in your browser
2. Right-click on each generated icon canvas
3. Select "Save image as..." and save as:
    - `icon-192.png` for the 192x192 version
    - `icon-512.png` for the 512x512 version

### Option 2: Use Your Design Tool

1. Create a square image with your LUKU logo
2. Export as PNG with the following specifications:
    - **icon-192.png**: 192x192 pixels
    - **icon-512.png**: 512x512 pixels
3. Use a solid background color (recommended: #4f46e5 or #7c3aed)
4. Ensure good contrast for the logo/text

### Option 3: Use Online Tools

-   [PWA Icon Generator](https://realfavicongenerator.net/)
-   [Favicon.io](https://favicon.io/)
-   [PWA Builder](https://www.pwabuilder.com/)

## Icon Design Guidelines

-   **Size**: Square format (1:1 aspect ratio)
-   **Background**: Solid color or simple gradient
-   **Logo**: Centered, high contrast
-   **Text**: If including "LUKU", use bold, readable font
-   **Colors**: Match your brand colors (#4f46e5, #7c3aed)
