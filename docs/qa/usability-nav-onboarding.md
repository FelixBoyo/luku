# LUKU Navigation & Onboarding – Usability Testing Plan (Pre-MVP)

## Objectives

- **Validate navigation clarity**: Can new users reliably find core surfaces (Discover, Mood Boards, Wardrobe, Marketplace)?
- **Evaluate first-run guidance**: Does the Lifestyle Hub onboarding banner help users choose a good starting path?
- **Assess cross-linking**: Do users understand how mood boards, outfit suggestions, and wardrobe relate?

## Core Tasks

Run each task as a think-aloud exercise. Ask participants to narrate what they expect before they click.

1. **Find outfit suggestions from the home experience**
   - Starting point: Signed-in user landing on `Lifestyle Hub`.
   - Task: “Without using the browser back button, show me where you’d go to get outfit ideas.”
   - Success criteria:
     - Participant uses either:
       - The desktop nav or mobile bottom nav to open **Discover** _or_
       - The CTA in `Lifestyle Hub` to “See outfit ideas”.
     - Participant articulates they are in the “outfit suggestions” area or similar language.

2. **Create and view mood boards**
   - Starting point: `Lifestyle Hub`.
   - Task A: “Create a new mood board for an upcoming event or trip.”
   - Task B: “Now show me where you’d go later to see that mood board again.”
   - Success criteria:
     - Participant navigates to **Mood Boards** via:
       - Desktop nav, mobile bottom nav, or CTA in Wardrobe/Discover/Lifestyle Hub.
     - Participant successfully creates a new board (even if naming is simple).
     - Participant can return to the Mood Boards view without help.

3. **Connect wardrobe to mood boards**
   - Starting point: `Wardrobe`.
   - Task: “You’re planning for a trip. Use your wardrobe to move toward a collection or mood board that helps you plan.”
   - Success criteria:
     - Participant notices the Mood Boards prompt in `Wardrobe`.
     - Participant correctly predicts what they’ll see after clicking “Open Mood Boards”.
     - Participant describes the relationship between wardrobe items and mood boards in their own words.

4. **Find orders and returns**
   - Starting point: Any main screen.
   - Task: “You bought something recently and want to check your order or start a return. Where would you go?”
   - Success criteria:
     - Participant discovers Orders/Returns via navigation (e.g., More / profile / utilities).
     - Participant expresses confidence that they’re in the right place.

## Session Structure (15–20 Minutes)

1. **Warm-up (2–3 mins)**
   - Ask about general familiarity with fashion apps or shopping platforms.
   - Clarify that this is a **product test**, not a test of the participant.

2. **Guided tasks (10–15 mins)**
   - Walk through the 4 core tasks above in order.
   - Encourage think-aloud; lightly probe when they hesitate (“What are you looking for?”).

3. **Wrap-up (3–5 mins)**
   - Ask: “If you were to come back tomorrow, where would you start?”
   - Ask what felt confusing or surprising about navigation or wording.

## Data Tagging Guidelines

When reviewing notes, tag each friction point by category:

- **IA (Information Architecture)** – User didn’t know _where_ something should live.
- **Visual hierarchy** – User didn’t notice a control/CTA even though it was on-screen.
- **Copy / wording** – Labels or descriptions were confusing or mismatched expectations.
- **Feedback & state** – User wasn’t sure if something worked or what happened after an action.

Start prioritization with issues that:

- Block completion of core tasks.
- Are mentioned by multiple participants.
- Relate directly to the new navigation and onboarding patterns (e.g., nav labels, Mood Boards naming, Lifestyle Hub banner).
