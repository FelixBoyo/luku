## Quick start

1. **Fill placeholders** — Search for `[` across all files: founder names, `$X` raise, traction metrics, market sizing sources.
2. **Export PDF** — Convert `EXECUTIVE_SUMMARY.md` to PDF for attachments (do not send raw `.md` to VCs).
3. **Build slides** — Copy `PITCH_DECK.md` sections into your slide tool; add product screenshots from `apps/mobile/`.
4. **Send Novastar email** — Use template #1 in `VC_OUTREACH.md`; attach 1-pager + deck.
5. **Prep for calls** — Review `MEETING_PREP.md`; rehearse 60-second pitch.
